_There's a rich tradition of Forths on the Mac. This one wants to *be* the Mac's
system language._

## TL;DR

- **What:** "Objective Forth" — a fork of [MF66](/posts/mf66) opened to pursue
  one idea: **Forth as the Mac's system language.**
- **How:** the engine drives **Cocoa directly**, so you build IDEs, games and
  apps from Forth.
- **Inherited:** the same LLVM-free token-IR optimizing Forth, compiler and
  benchmarks from MF66. (The crate + binaries are still named `mf66` for now.)
- **Get it:** [Downloads](#download-run) · [Source](https://github.com/albanread/MF67)

## Where it sits

MF67 is the Cocoa-driving end of the Forth lineage, kin to
[MacModula2](/posts/macmodula2)'s "a class is an ObjC object" thesis but from a
Forth angle. See the [timeline](/timeline).

## What it is

> _From the README —_ "MF67 is a fork of MF66 — the same LLVM-free token-IR
> optimizing Forth… opened to pursue one idea: **Forth as the Mac's system
> language.** The engine drives Cocoa directly, so you build IDEs, games, and
> apps from Forth." See `docs/design/forth-cocoa.md`.

## Why I built it

- _The Forth-on-Mac tradition, taken seriously as a system language._
- _Wanting to write real Cocoa apps in Forth, not toy demos._

## How it works

- **Forth → Cocoa:** _how words map to `objc_msgSend`; how classes/delegates are
  expressed; where `cocoa_data`-style metadata comes in. See
  `docs/design/forth-cocoa.md`._
- **Inherited engine:** _the MF66 token-IR compiler and macro-assembler underneath._
