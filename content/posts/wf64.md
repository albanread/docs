_Alex McDonald's 32-bit WF32 STC Forth, ported up to 64-bit Windows — its `.masm`
kernel assembled and JIT-loaded through the JASM macro assembler, LLVM and all._

## TL;DR

- **What:** a 64-bit **subroutine-threaded (STC)** ANS Forth for Windows x86-64,
  ported from Alex McDonald's WF32 primitives and STC compiler.
- **How:** a MASM-flavoured kernel (`kernel/*.masm`) assembled and JIT-loaded at
  process start through **[JASM](/posts/jasm)**, which at this point rode
  **LLVM-MC + MCJIT** — so WF64 ships a ~**71 MB `LLVM-C.dll`**.
- **Where it goes:** WF64 → [WF65](/posts/wf65) (native encoder, LLVM demoted to an
  oracle) → [WF66](/posts/wf66) (token IR, LLVM removed).
- **Get it:** [Downloads](#download--run) · [Source](https://github.com/albanread/WF64)

## Where it sits

The Forth lineage runs **wf32 STC** (Alex McDonald, 2020) → **WF64** →
[WF65](/posts/wf65) → [WF66](/posts/wf66) → [MF66](/posts/mf66) (Apple Silicon) →
[MF67](/posts/mf67). WF64 is the "reborn at 64-bit" step, and the high-water mark
of the line's LLVM dependency. See the [timeline](/timeline).

## What it is

> _From the README —_ "The Forth compiler here is based on the WF32 STC compiler…
> The WF32 primitives and STC compiler are the starting point; on top of that we
> overlay a port of ANS Forth." The kernel was ported from WF32 "with a fair amount
> of automated extraction and testing." "LLVM is used in the core. After Forth is
> built, the Forth compiler itself does not use LLVM."

WF32 itself is **Alex McDonald's** 32-bit Win32 STC Forth (BSD-2-Clause), adopted
as the seed of this line — not original to this portfolio.

## How it works

- **STC codegen:** colon definitions are raw RWX bytes — `compile,` emits an `E8`
  rel-call, `;` emits `C3` (ret). ABI: RAX = TOS, RBP = data-stack pointer,
  RBX = user pointer, RSP = return stack, R15 reserved for locals.
- **Assembled via JASM:** the `.masm` kernel is encoded by JASM's **LLVM-MC** path
  and loaded/resolved through **MCJIT** — the "Forth embedded inside an LLVM macro
  assembler" arrangement (and the source of the ~71 MB LLVM dependency).
- **Runtime:** a paged GC (the shared collector, `newgc-core`) plus managed dynamic
  strings; a `CODE` escape hatch to define primitives inline in JASM; a `LET` infix
  FP expression evaluator with register-allocated SSE.
- **IDE:** a Win32 **MDI IDE** rendered with Direct2D/DirectWrite/Direct3D 11 (the
  `iGui` shell), with REPL, live stack viewer, diagnostic log, and a VEH/SEH crash
  dumper.
